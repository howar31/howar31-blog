不論你有沒有玩過Firefox套件  

沒玩過的 在下面看看有沒有很酷的東西趕緊裝在你的Google Chrome上面！  

有玩過的 在下面看看有沒有很眼熟的套件是不是也來到Google Chrome了！  

  

以下我只做簡略的介紹 詳細的介紹(包括套件截圖)直接點進連結就可以看到  

  

\==  

  

喔對了 下面將分為兩大類  

  

公用電腦: 這些套件不需要登入也不會紀錄任何東西，就算在公用電腦也適合安裝  

私人電腦: 這些套件需要登入某些服務(Google、Facebook等)，建議只在個人電腦上使用  

  

另外 我稍微用「==」分隔線把不同類型的套件做個小小區分  

而我個人強力推薦的套件我會標上**這個顏色** 歡迎大家一起推廣好套件！  

  

\==公用電腦==  

  

Chrome Touch  

讓你可以用滑鼠直接拖動頁面，就好像Adobe PDF或iPhone那樣拖拉  

[https://chrome.google.com/extensions/detail/ncegfehgjifmmpnjaihnjpbpddjjebme](https://chrome.google.com/extensions/detail/ncegfehgjifmmpnjaihnjpbpddjjebme)  

  

**Chrome Reload**  

自動重新整理頁面的功能，每個分頁可以獨立設定  

[https://chrome.google.com/extensions/detail/njoipeaphfnaplplihpbgndfojhdhmjo](https://chrome.google.com/extensions/detail/njoipeaphfnaplplihpbgndfojhdhmjo)  

  

**SmoothScroll**  

平滑的捲動頁面，而不是原本的一格一格的感覺  

[https://chrome.google.com/extensions/detail/cccpiddacjljmfbbgeimpelpndgpoknn](https://chrome.google.com/extensions/detail/cccpiddacjljmfbbgeimpelpndgpoknn)  

  

Timer  

小小計時器，可以設定時間倒數，時間到了會跳出訊息警告  

[https://chrome.google.com/extensions/detail/hepmlgghomccjinhcnkkikjpgkjibglj](https://chrome.google.com/extensions/detail/hepmlgghomccjinhcnkkikjpgkjibglj)  

  

Session Manager  

瀏覽紀錄管理器，可以管理紀錄目前的分頁，方便一次開啟整組分頁  

[https://chrome.google.com/extensions/detail/bbcnbpafconjjigibnhbfmmgdbbkcjfi](https://chrome.google.com/extensions/detail/bbcnbpafconjjigibnhbfmmgdbbkcjfi)  

  

Tab Menu  

分頁管理，可以在一個下拉式功能表裡看到所有的分頁，並且有搜尋功能  

[https://chrome.google.com/extensions/detail/galfofdpepkcahkfobimileafiobdplb](https://chrome.google.com/extensions/detail/galfofdpepkcahkfobimileafiobdplb)  

  

TooManyTabs for Chrome  

Tab Menu + Read It Later的套件，可以總攬目前所有分頁並可把暫時不看的暫存  

[https://chrome.google.com/extensions/detail/amigcgbheognjmfkaieeeadojiibgbdp](https://chrome.google.com/extensions/detail/amigcgbheognjmfkaieeeadojiibgbdp)  

  

\==  

  

下面兩個基本功能完全一樣，只是介面的不同  

Classic版本是把按鈕放在網址列裡比較不佔空間，介面也比較美觀，推薦使用  

  

IE Tab  

[https://chrome.google.com/extensions/detail/hehijbfgiekmjfkfjpbkbammjbdenadd](https://chrome.google.com/extensions/detail/hehijbfgiekmjfkfjpbkbammjbdenadd)  

  

**IE Tab Classic**  

[https://chrome.google.com/extensions/detail/miedgcmlgpmdagojnnbemlkgidepfjfi](https://chrome.google.com/extensions/detail/miedgcmlgpmdagojnnbemlkgidepfjfi)  

  

\==  

  

Bubble Translate  

可以直接用快速鍵反白網頁上的文字，並且跳出泡泡翻譯訊息  

[https://chrome.google.com/extensions/detail/jlhlebbhengjlhmcjebbkambaekglhkf](https://chrome.google.com/extensions/detail/jlhlebbhengjlhmcjebbkambaekglhkf)  

  

**Google Dictionary Lookup**  

跟Bubble Translate很像，不過這是查詢Google字典，因此資訊更多，推薦使用  

[https://chrome.google.com/extensions/detail/ipdjaafajlfiopcppipdinmcjbcpofhd](https://chrome.google.com/extensions/detail/ipdjaafajlfiopcppipdinmcjbcpofhd)  

  

**Tong Wen for Chrome**  

同文堂，老牌的繁簡轉換套件  

[https://chrome.google.com/extensions/detail/geibnfhckmgdhjicggkjdafecgclammb](https://chrome.google.com/extensions/detail/geibnfhckmgdhjicggkjdafecgclammb)  

  

**Google Translate**  

使用Google Translate技術，可以直接把整個頁面翻譯成指定語言  

[https://chrome.google.com/extensions/detail/aapbdbdomjkkjkaonfhkkikfgjllcleb](https://chrome.google.com/extensions/detail/aapbdbdomjkkjkaonfhkkikfgjllcleb)  

  

\==  

  

ForeCastFox  

老牌Firefox氣象預報套件，一看名字就知道是Firefox轉來的......orz  

[http://www.chromeextensions.org/utilities/forecastfox/](http://www.chromeextensions.org/utilities/forecastfox/)  

  

BBC News  

提供即時BBC新聞頭條  

[https://chrome.google.com/extensions/detail/demajmfijlhlomgneclfgajekhmomhof](https://chrome.google.com/extensions/detail/demajmfijlhlomgneclfgajekhmomhof)  

  

\==  

  

**Beautify Facebook**  

整體美化Facebook介面，建議搭配Facebook Fixer使用  

[https://chrome.google.com/extensions/detail/ipnenhkngeiigfbhacdhadcnjjklhblm](https://chrome.google.com/extensions/detail/ipnenhkngeiigfbhacdhadcnjjklhblm)  

  

**Facebook Fixer**  

Facebook強力擴充功能套件，提供非常多方便功能，建議搭配Beautify Facebook使用  

[https://chrome.google.com/extensions/detail/egjpclbmbbcndoljcjfleefnpjbiemdl](https://chrome.google.com/extensions/detail/egjpclbmbbcndoljcjfleefnpjbiemdl)  

  

AlWittizer Facebook Enhancer  

這套件同時美化介面並強化功能，不需要搭配Fixer或Beautify，依個人喜好選用  

[https://chrome.google.com/extensions/detail/jmlfacceemopmehiobgdblbbhomlekhf](https://chrome.google.com/extensions/detail/jmlfacceemopmehiobgdblbbhomlekhf)  

  

上面這三款 不需要同時安裝全部  

建議使用「Beautify + Fixer」或是單一一個「AlWittizer」即可  

  

\==  

  

**AutoPagerize for Chrome**  

自動讀取下一頁的內容整合成一頁，支援多個網站與論談，讓你不用一直按「下一頁」  

[https://chrome.google.com/extensions/detail/igiofjhpmpihnifddepnpngfjhkfenbp](https://chrome.google.com/extensions/detail/igiofjhpmpihnifddepnpngfjhkfenbp)  

  

**Google Quick Scroll**  

在Google搜尋並且進入頁面以後，可以直接跳到包含關鍵字的位置  

[https://chrome.google.com/extensions/detail/okanipcmceoeemlbjnmnbdibhgpbllgc](https://chrome.google.com/extensions/detail/okanipcmceoeemlbjnmnbdibhgpbllgc)  

  

**Google Preview**  

在Google搜尋旁邊加上頁面預覽圖  

[https://chrome.google.com/extensions/detail/hcjdanpjacpeeppdjkppebobilhaglfo](https://chrome.google.com/extensions/detail/hcjdanpjacpeeppdjkppebobilhaglfo)

Docs PDF/PowerPoint Viewer (by Google)  

讓所有PDF和PPT連結直接使用線上「Google文件」開啟  

[https://chrome.google.com/extensions/detail/nnbmlagghjjcbdhgmkedmbmedengocbn](https://chrome.google.com/extensions/detail/nnbmlagghjjcbdhgmkedmbmedengocbn)  

  

**Cooliris**  

超酷炫3D幻燈片套件，支援Google圖像搜尋、Facebook等多個網站  

[https://chrome.google.com/extensions/detail/noocneohefmdhonidldnlhaainpiomkp](https://chrome.google.com/extensions/detail/noocneohefmdhonidldnlhaainpiomkp)  

  

**ChromeMUSE - Multi-URL Shortener/Expander**  

自動縮址套件，點擊按鈕後可以獲得目前頁面的短網址  

[https://chrome.google.com/extensions/detail/digfdjelalmeldlplgcapchelgnlkomc](https://chrome.google.com/extensions/detail/digfdjelalmeldlplgcapchelgnlkomc)

**Gmail Checker**

[https://chrome.google.com/extensions/detail/gffjhibehnempbkeheiccaincokdjbfe](https://chrome.google.com/extensions/detail/gffjhibehnempbkeheiccaincokdjbfe)

[https://chrome.google.com/extensions/detail/ookhcbgokankfmjafalglpofmolfopek](https://chrome.google.com/extensions/detail/ookhcbgokankfmjafalglpofmolfopek)  

  

Google Reader Notifier (by Google)  

檢查Google閱讀器有沒有新訊息，並在圖示上顯示新訊息數量  

[https://chrome.google.com/extensions/detail/apflmjolhbonpkbkooiamcnenbmbjcbf](https://chrome.google.com/extensions/detail/apflmjolhbonpkbkooiamcnenbmbjcbf)  

  

One Number  

整合Gmail、Google Reader、Google Voice、Google Wave的訊息檢查  

[https://chrome.google.com/extensions/detail/cfkohgkpafhkpdcnfadadcibfboapggi](https://chrome.google.com/extensions/detail/cfkohgkpafhkpdcnfadadcibfboapggi)

**Send from Gmail**

Send from Gmail (no button)

**Google Tasks**

Google Talks
