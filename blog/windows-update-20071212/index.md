只要點下去就會開始安裝  
  
Update的版本為20071212  
  
封裝時間是20080101  
  
[![](http://2.bp.blogspot.com/_FRalJrkoHMQ/R7L_lDTV-uI/AAAAAAAAAB0/v8EPZQbq2fs/s400/%E8%A7%A3%E5%A3%93.bmp)](http://2.bp.blogspot.com/_FRalJrkoHMQ/R7L_lDTV-uI/AAAAAAAAAB0/v8EPZQbq2fs/s1600-h/%E8%A7%A3%E5%A3%93.bmp)

所以不會有什麼病毒的疑慮XD  
  
如果想看裡面有什麼  
  
可以用WinRAR打開這個檔案

載點若失效了請回報＠＠  
  
\==  
  
\-下載說明- 
  
因為這個檔案大小超過100MB  
  
被便當狗強制分割成兩個檔案＝ w ＝a  
  
所以要這樣做......  
  
下載畫面  
[![](http://1.bp.blogspot.com/_FRalJrkoHMQ/R7MCOjTV-xI/AAAAAAAAACM/MfDT2TOEmhY/s400/%E4%B8%8B%E8%BC%89%E8%AA%AA%E6%98%8E.bmp)](http://1.bp.blogspot.com/_FRalJrkoHMQ/R7MCOjTV-xI/AAAAAAAAACM/MfDT2TOEmhY/s1600-h/%E4%B8%8B%E8%BC%89%E8%AA%AA%E6%98%8E.bmp)  
  
請點擊下載  
「Part #1: WindowsXP\_Update\_20071212.exe.aa」  
「Part #2: WindowsXP\_Update\_20071212.exe.ab」  
「WindowsXP\_Update\_20071212.exe.badongo」  
「Windows File Merger」  
  
共四個檔案  
  
檔案被拆成.aa和.ab兩個檔  
  
而Reference File是Badongo合併檔案實用的參考檔  
  
而Windows File Merger是合併檔案的批次檔  
  
通通下載好後放在同一個資料夾  
  
然後點擊WindowsXP\_Update\_20071212.exe.bat就可以囉！^^
